# Tactics and matchday patterns

Touchline 26 will use these patterns as inspiration only, with original visual language and domain rules.

| Area | Pattern to adapt |
|---|---|
| Pre-match hub | Bring team report, opposition report, expectations, player mood, key stats, and tactical preparation into one actionable pre-match flow. |
| Squad selection | Let the manager choose the XI and bench from the tactics surface, use position slots, drag players into roles, compare suitability, save/load plans, and ask the assistant for a selection. |
| Tactical model | Support player roles and duties, separate in-possession and out-of-possession structures, mentality, pressing, tempo, width, transition, and opposition-specific instructions. |
| Match navigation | Use swipeable or tabbed match views: overview, player ratings, match stats, action zones, attacking zones, player stats, latest scores, and live table. |
| Match actions | Surface shortcut actions for mentality, tactical changes, substitutions, touchline shouts, opposition instructions, and team talks. |
| Match presentation | Support full-pitch or commentary-only views, highlights, timeline, speed controls, overlays, and key-event attention states. |
| Team talks | Offer pre-match, half-time, and full-time talks with mood choices and immediate player-reaction feedback. |
| Post-match | Provide team meeting, positives/negatives, player ratings, stats, injury/medical updates, and follow-up decisions. |

The central product principle is to keep the match screen information-rich but action-first. A manager should always be able to see what happened, why it happened, and what can be changed next.
